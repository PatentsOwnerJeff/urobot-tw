UROBOT® TW

開源的台灣泌尿科臨床決策輔助 AI — 回答逐點標註指引出處

GitHub 開源程式碼 快速開始

這是什麼？

UROBOT® TW 採用檢索增強生成（RAG）架構：使用者提問時，系統先從泌尿科臨床指引中檢索最相關段落，再由大語言模型依據段落作答並標註出處，確保每個答案可追溯、可驗證。與德國 DKFZ 發表於 ESMO RWD（2024）之 UroBot 研究同架構（該研究於歐洲泌尿專科筆試達 88.4% 正確率，超越專科醫師平均 68.7%），並針對台灣在地化。

指引為本、附出處

整合 EAU 指引語料（繁中摘要跨語檢索），規劃納入 TUA 指引與健保給付規範，每個回答標註引用段落。

不綁定模型供應商

Claude API、本地 Ollama 開源模型、純檢索模式三種都能跑；醫院可地端部署，資料不出門。

內建評測系統

以專科考題正確率（RoCA）為指標的評測工具，對標國際研究成果，成績公開可驗證。

完全開源

程式碼以 Apache-2.0 授權公開於 GitHub，歡迎泌尿科醫師與工程師社群共同參與。

本系統為研發中專案，輸出僅供臨床參考與教育用途，不構成醫療建議，最終決策由醫師負責。
