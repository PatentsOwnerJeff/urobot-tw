UROBOT® TW

開源的台灣泌尿科臨床決策輔助 AI — 回答逐點標註指引出處

GitHub 開源程式碼 下載 v0.1.0
v0.1.0 已發布 — 488 段健保與示範語料隨附，不需 API key 即可執行；臨床指引需自行建置

這是什麼？

UROBOT® TW 採用檢索增強生成（RAG）架構：使用者提問時，系統先從泌尿科臨床指引中檢索最相關段落，再由大語言模型依據段落作答並標註出處，確保每個答案可追溯、可驗證。與德國 DKFZ 發表於 ESMO RWD（2024）之 UroBot 研究同架構（該研究於歐洲泌尿專科筆試達 88.4% 正確率，超越專科醫師平均 68.7%），並針對台灣在地化。

台灣健保給付規範

隨附 478 段健保語料：診療項目 391、藥品 69、藥品給付規定條文 18，全部取自政府開放資料，可合法散布。這是國外系統沒有的部分。

不綁定模型供應商

Claude API、本地 Ollama 開源模型、純檢索模式三種都能跑；醫院可地端部署，資料不出門。

跨語與跨用語檢索

健保條文寫「前列腺增生」，臨床說「攝護腺肥大」，民眾說「威而鋼」。84 組同義詞對照讓三種說法都問得到。

不知道就說不知道

語料庫沒有的主題一律拒答，並告訴你要補哪一本指引、指令怎麼下 —— 不拿字面沾邊的段落硬湊成答案。涵蓋範圍以 scope.json 明示宣告。

完全開源

程式碼以 Apache-2.0 授權公開於 GitHub，131 個測試、CI 把關，歡迎泌尿科醫師與工程師社群共同參與。

怎麼跑

git clone https://github.com/PatentsOwnerJeff/urobot-tw.git
cd urobot-tw
pip install -r requirements.txt
python ingest.py     # 488 段語料已隨 repo 附上
python app.py        # → http://127.0.0.1:5000
                     # macOS 的 5000 埠被 AirPlay 佔用時：UROBOT_PORT=5050 python app.py
開箱能回答的範圍很窄，這點先講清楚。隨附的 488 段裡有 478 段是健保語料，臨床指引只有 10 段示範。所以開箱狀態只答得了「台灣健保給付規範」相關問題，其他泌尿科主題會直接拒答，並在回覆裡附上要補哪一本指引、下載網址、可複製的建置指令，以及 scope.json 要怎麼改。學會指引受著作權保護不能隨程式散布，這是刻意的設計，不是沒做完。
本站沒有線上試用。UROBOT TW 需在自己的電腦或機構內部署 —— 這是刻意的設計：搭配本地 Ollama 或純檢索模式時，病人相關的提問不會離開你的環境。

目前的限制

  • 學會指引（EAU 等）著作權屬原機構，不隨程式散布，需自行以 build_corpus.py 從官網下載建置
  • 尚未以泌尿專科甄審題庫做過正式評測，目前僅有 12 題示範考題，還沒有可對外宣稱的分數
  • 檢索為純 BM25，對「同義但完全不同字」的情形仍有限，向量檢索在路線圖上
  • 涵蓋範圍由 scope.json 人工維護：試過以 BM25 分數與 IDF 加權詞彙覆蓋率自動判斷，兩者在未涵蓋主題上的分數反而比已涵蓋主題高（jieba 會把未收錄的醫學複合詞拆成語料裡都有的字），統計方法在這個規模的語料上不可靠。新增指引語料後必須手動更新 scope.json，系統才會開始回答該主題
  • 健保給付規定會改版，語料標註了擷取日期與條文版本，但實際給付一律以健保署最新公告為準
